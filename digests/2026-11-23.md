### What the patch does
The cost-tracking page lists the providers that have built-in prices. That list has drifted from the price table Phoenix actually ships, which is `src/phoenix/server/cost_tracking/manifests/v1.json`, generated by `scripts/cost_tracking/sync_models.py`.

| Doc said | Reality on `main` | Change |
|---|---|---|
| No Mistral entry | 52 `mistralai` models, plus Mistral embeddings | Added, using the audit's own proposed wording |
| No Together, Z.ai, MiniMax or Meta | 77, 17, 7 and 7 models | Added (the audit's "Low" gap) |
| No Perplexity | 9 Sonar models; `sync_models.py` keeps `perplexity/sonar*` | Added |
| No Amazon Bedrock | About 150 Bedrock Claude IDs, including regional `us.`/`eu.`/`global.` IDs (priced at Bedrock's rate since #18052) | Added |
| "Fireworks AI" | 0 Fireworks models; there is no `fireworks/` prefix in `sync_models.py` | Removed |
| "Claude 1.x, Claude 2.x, Claude 3.x, Claude 3.5, Claude 4.x" | `sync_models.py` excludes `claude-2.*` and `claude-instant.*`. Direct-API entries are Claude 4.x and 5.x, and Claude 3.x appears only as Bedrock IDs | "Claude 4.x and Claude 5.x"; Claude 3.x is noted under Bedrock |
| "Gemini 1.x, 2.x, 3.x" | `gemini-1.*` is excluded, leaving 2.x and 3.x | Gemini 1.x dropped; Gemini embeddings added |
| Groq: "Llama, Mixtral, Gemma" | Groq entries are GPT-OSS, Qwen and Llama Prompt Guard | Corrected |
| OpenAI: no embeddings mentioned | `text-embedding-3-*` and `ada-002` are priced (embedding spans are now costed, #17788) | Added |
| "Other providers: additional models as they become available" | The table auto-updates daily | Replaced with one sentence pointing to Settings → Models and the bundled table, and saying unlisted models need a custom model |

The last row is the durability fix. The table syncs from LiteLLM every day, so the page now points readers to the source of truth instead of implying that the bullet list is exhaustive.

> "Phoenix calculates LLM costs from a price table that syncs from LiteLLM every day. Their docs page listed which providers have built-in prices, and a maintainer's weekly audit flagged that Mistral was missing.
