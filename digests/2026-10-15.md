### What the patch does
Phoenix's own playground stopped offering Claude 3.5 Sonnet after Anthropic retired it (commit b978e7c, #16870). Five documentation examples still tell users to call it, so copying those snippets now fails against the Anthropic API.

The patch replaces each retired ID with `claude-haiku-5-5`. This is the replacement the audit itself proposes, and it is in Phoenix's current Anthropic model list in `src/phoenix/server/api/helpers/playground_clients.py`.
