## YOUR TASK: DAILY MAINTAINER

Repos for this task: the portfolio repos marked as created in
github-growth-ops/roadmap.md. Attach github-growth-ops read-only to find them,
then attach only the one repo you change.

Pick one of Arjun's existing portfolio repos and make one genuinely useful
improvement. Skip any repo that already has an open claude/ pull request.

Look for, in this order:
1. Failing tests or broken CI
2. Outdated or vulnerable dependencies
3. Open issues on the repo that are small and clear
4. Missing tests for existing code
5. Unclear or out-of-date documentation
6. Small refactors that make the code easier to understand

Make one focused change on a new branch. Run the tests. Open a pull request
into that repo explaining what you changed and why it matters.

If nothing genuinely needs doing today, make no changes and open no pull
request. End with one line saying so. A day with no changes is better than
a day with a pointless one.

Do not merge.
