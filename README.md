# github-growth-ops

Control repo for my GitHub growth routines. Every routine reads from this repo
and reports back by opening a pull request. Nothing is merged or submitted
upstream without my review.

| File | Purpose |
| --- | --- |
| `persona.md` | Who the routines work for. Read at the start of every run. |
| `targets.md` | Open-source projects worth contributing to (Track 1 maintains it). |
| `roadmap.md` | Portfolio repos and their milestones (Track 2 maintains it). |
| `digests/` | Weekly contribution digests from the Contribution Scout. |
| `patches/` | Prepared changes for projects I haven't forked yet. |
| `routines/` | The prompt for each routine: shared rules plus one task file per routine. |
